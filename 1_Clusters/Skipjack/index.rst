Skipjack Cluster
================

The Skipjack cluster is a high-performance computing (HPC) system operated by ARCH at Johns
Hopkins University.

These are "shared resources", therefore we expect all users to comply with policies on passwords,
security guidelines, resource utilization and best practices, and privacy issues. See :doc:`/4_Support/Citizen`
for more information.

If users have any questions about these policies, please send an email to
`help@arch.jhu.edu <mailto:help@arch.jhu.edu>`_

To begin, see the user guide for information regarding account creation and login.


.. admonition:: Skipjack Beta Phase and Access Notice
   :class: warning

   We are currently beta testing Skipjack in preparation for full migration!
   During this testing phase, access is temporarily limited to a select group of
   early users. Stay tuned for wider availability soon.
