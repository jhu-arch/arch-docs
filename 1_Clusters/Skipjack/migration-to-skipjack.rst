===================================
Skipjack Frequently Asked Questions
===================================


Answers to Frequently Asked Questions
=====================================

#. **Can I be a beta tester?**

   At this time, access is restricted to previously selected beta testers.

#. **Will my project be migrated/mapped to Skipjack?**

   No. You will need to create a new project following the steps outlined in the :ref:`Skipjack User Guide`.

#. **Will users, groups, and file permissions carry over?**

   No. Users will need to create new accounts on the system following the steps outlined in :ref:`Skipjack User Guide`.
   Our recommended method, :ref:`Data Transfer with Globus`, can transfer files with permissions intact if all
   the same users are present on Skipjack before the file transfer.

#. **How can I prepare for migrating to Skipjack?**

   **Data Review** -- Please review your current data use. Remove redundant, obsolete or trivial data.
   Identify data not used for active research and move it to an appropriate storage location. Reducing your current
   data usage profile as much as possible will make migration smoother.

   **Software Review** -- Please review procedures for compiling code or building software. When switching systems,
   it is often necessary to recompile code or rebuild environments.

#. **Can I, as a PI, designate a student or program manager to handle the transition on my behalf?**

   Yes. Many tasks can be delegated to a Proxy Account Manager (see :ref:`Assign Proxy Account Managers` for the steps
   to designate a manager).

#. **What does it cost to move to Skipjack?**

   Moving to Skipjack does not trigger any immediate billing changes. Free compute access will
   remain available for now. Please be assured that there will be no billing without substantial
   prior communication, and there will never be any form of retroactive billing to users.

If you have additional questions not covered here, please contact us at `help@arch.jhu.edu <mailto:help@arch.jhu.edu>`_.
